# .github

Organization profile and shared community files for [Cozy Vibe Labs](https://github.com/cozy-vibe-labs).

## Contents

| Path                | Purpose                                                    |
| ------------------- | ---------------------------------------------------------- |
| `profile/README.md` | The public profile shown on the organization's GitHub page |
| `profile/assets/`   | Images used by the profile, such as the hero SVG           |

Default community health files (for example `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, issue and pull request templates) can be added to this repository. GitHub uses them for every repository in the organization that does not have its own version.
